# 생활 전기 숏츠 채널 자동화

잘된 숏츠의 구조를 학습해서, 우리 주제(전기·현장 데이터·지능형제어반)를 그 구조로 만드는 도구입니다. 대중 채널로 구독자를 모으고, 그 파생 효과로 현장 데이터의 중요성을 알리는 것이 목적입니다.

## 흐름

1. **수집 (`collect.py`)**
   - 벤치마크 채널의 숏츠 길이·조회수·좋아요와 설명란(대본 요약)을 받습니다.
   - `YOUTUBE_API_KEY`가 있으면 YouTube Data API로 채널의 모든 숏츠 상세를 받습니다. 500편에 20단위쯤 써서 하루 한도(10,000단위)에 한참 못 미칩니다.
   - 키가 없거나 한도를 넘으면 공개 페이지를 yt-dlp로 읽는 방식으로 자동 전환합니다. 이 방식은 상위·하위·키워드 영상만 상세를 받고, 봇 확인이 걸리면 길이·좋아요가 빕니다.
   - 어느 방식이든 180초를 넘는 영상은 숏츠가 아니므로 뺍니다.
2. **분석 (`analyze.py`)**
   - 잘된 영상과 안된 영상의 제목, 길이, 반응 차이를 표로 냅니다.
   - 결과 스냅숏: `analysis.md`
3. **구조 (`structure.md`)**
   - 분석에서 뽑은 제목 규칙, 6비트 대본 구조, 말투, 화면 규칙, 우리 채널 규칙입니다.
   - 사람이 다듬는 문서입니다.
4. **대본 (`generate.py`)**
   - 주제 한 줄을 넣으면 `structure.md`를 따르는 대본 초안을 만듭니다.
   - Claude API(`ANTHROPIC_API_KEY`)가 필요합니다.
5. **감수**
   - 대본마다 있는 감수 체크리스트를 동인엔시스 대표이사가 확인합니다.
   - 확인이 끝나야 제작으로 넘어갑니다.
6. **제작·업로드 (아직 없음)**
   - 장면 영상 생성, AI 음성, 한글 자막 합성, 업로드 순서로 진행합니다.
   - 업로드할 때 '변경되거나 합성된 콘텐츠' 표시를 켭니다.

```sh
pip install -r shorts/requirements.txt
python3 shorts/collect.py @신비한_건축사전_1 --top 60 --bottom 40 --match "전기|전력|발전|에어컨"
python3 shorts/analyze.py 신비한_건축사전_1
python3 shorts/generate.py "엘리베이터가 정전돼도 멈춘 층에서 문이 열리는 이유" --out shorts/scripts/06-elevator.md
```
