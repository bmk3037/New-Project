# 05. 공장 벽마다 붙어 있는 회색 철문의 정체

- 제목: 공장 벽마다 붙어 있는 회색 철문의 정체 (20자)
- 분류: 제어반·데이터 (10%)
- 목표 길이: 100초
- 데이터 연결: 영상 전체, 지능형제어반

| 비트 | 화면 (생성 프롬프트) | 내레이션 |
|---|---|---|
| 1. 장면 열기 | 공장 통로 벽을 따라 회색 철문 상자들이 줄지어 서 있다. 느린 트래킹. | 공장이나 아파트 지하에 가면, 벽에 회색 철문 상자가 줄지어 서 있습니다. 대부분 큰 두꺼비집이겠거니 하고 지나가시죠. |
| 2. 균열 | 철문이 열리며 내부가 드러난다. 차단기 옆에 작은 컴퓨터 모듈과 수많은 배선. | 열어보면 다릅니다. 차단기만 있는 게 아니라, 작은 컴퓨터가 들어 있거든요. |
| 3. 딜레마 | 기계 수십 대가 따로 켜지고 꺼지며 엉키는 장면. | 기계 수십 대를 사람이 일일이 켜고 끄면 순서가 꼬이고, 기계마다 컴퓨터를 따로 달면 서로 말이 안 통합니다. |
| 4. 발상 전환 | 상자 속 PLC 모듈에서 붉은 신호선이 센서, 모터, 밸브로 뻗어 나간다. | 그래서 한 상자에 모았습니다. PLC라는 이 작은 컴퓨터가 센서 신호를 받아서, 정해진 순서대로 모터를 켜고 밸브를 열죠. 사람 대신 손을 움직이는 두뇌인 셈입니다. |
| 선택 비트: 반전 | 상자를 지나가는 붉은 숫자들이 바닥으로 흩어져 사라진다. | 그런데 이 상자는 오랫동안 움직이는 일만 했습니다. 전류, 온도, 진동, 수많은 숫자가 매 순간 이 안을 지나가는데, 대부분은 기록되지 않고 그냥 흘러갔죠. |
| 5·6. 지금 여기로 | 흩어지던 숫자들이 모여 화면 위 그래프로 쌓인다. 다시 회색 철문 통로. | 요즘 제어반에 '지능형'이라는 이름이 붙는 이유가 여기 있습니다. 지나가던 숫자를 버리지 않고 쌓아서, 기계가 멈추기 전에 먼저 알려주거든요. 다음에 회색 철문을 보시면, 그 안에서 공장의 하루가 숫자로 쌓이고 있다고 생각하시면 됩니다. |

이 편은 홍보 비중이 높습니다. 생활 전기 편으로 구독자를 먼저 모은 뒤에 올리는 게 좋습니다.

## 감수 체크리스트

- [ ] 제어반·분전반·MCC 구분을 이 정도로 뭉뚱그려도 현장 사람이 보기에 어색하지 않은지
- [ ] PLC 역할 설명
- [ ] 동인엔시스 지능형제어반 실제 기능(수집 항목, 알림 방식)과 내레이션이 어긋나지 않는지

### 고칠 문장

- **비트 1:** "공장이나 아파트 지하에 가면, 벽에 회색 철문 상자가 줄지어 서 있습니다." → "공장에 가면, 벽에 회색 철문 상자가 줄지어 서 있습니다." 아파트 지하 상자는 대부분 분전반이라 비트 2와 어긋납니다.
- **비트 2:** "열어보면 다릅니다. 차단기만 있는 게 아니라, 작은 컴퓨터가 들어 있거든요." → "그런데 그중 몇은 다릅니다. 열어보면 차단기 옆에 작은 컴퓨터가 들어 있거든요." 두꺼비집인 상자도 많다는 사실을 살립니다.
- **비트 3:** "기계마다 컴퓨터를 따로 달면 서로 말이 안 통합니다." → "기계마다 따로 놀면 서로 박자를 맞추기가 어렵습니다." 기계별 제어기는 통신망으로 이어 쓰기 때문입니다.
- **선택 비트:** "그런데 이 상자는 오랫동안 움직이는 일만 했습니다." → "그런데 많은 공장에서 이 상자는 오랫동안 움직이는 일만 했습니다." 큰 공정 설비는 오래전부터 기록해 왔습니다.
- **비트 5·6:** "지나가던 숫자를 버리지 않고 쌓아서, 기계가 멈추기 전에 먼저 알려주거든요." → "지나가던 숫자를 버리지 않고 쌓아서, 평소와 다른 숫자가 보이면 먼저 알려주거든요." 고장을 반드시 미리 안다는 약속을 빼서 광고 톤을 낮춥니다.

### 사람이 확인할 것

- **동인엔시스 제품과 맞는지:** 내레이션은 특정 제품을 말하지 않지만, 설명란과 채널 목적상 회사 제품과 어긋나면 안 됩니다. 다음 세 가지를 확인해 주세요.
  - 전류·온도·진동을 실제로 받는지. 진동은 보통 별도 센서가 필요합니다.
  - 값을 저장해 이력으로 쌓는지, 아니면 현재값만 보여주는지.
  - 알림이 정해 둔 기준값을 넘을 때 오는지, 평소 추세와 다를 때 오는지. 앞쪽이면 "평소와 다른 숫자" 표현도 "기준을 넘는 숫자"로 바꿔야 합니다.
- **현장 감각:** 제어반·분전반·MCC를 "회색 철문 상자" 하나로 묶은 표현이 현장 사람에게 어색하지 않은지 봐 주세요. 공장 통로 장면이면 MCC와 제어반이 섞여 서 있는 게 자연스럽다고 봅니다.
- **광고 톤:** 이 편은 영상 전체가 데이터 연결이라, `structure.md`의 "데이터 연결은 한 문장" 규칙의 예외입니다. 수정안을 적용해도 제품 소개처럼 들리는지 한 번 들어 봐 주세요.

## 설명란

공장 벽의 회색 철문은 제어반입니다. 기계를 움직이던 상자가 이제는 숫자를 남깁니다.
