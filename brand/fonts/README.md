# 서체

홈페이지와 CI 가이드는 외부 CDN 연결 없이 로컬 서체를 사용합니다.

- Pretendard Variable v1.3.9: orioncactus/pretendard, SIL OFL (`Pretendard-LICENSE.txt`)
- Archivo 800 Latin: @fontsource/archivo v5.2.5, SIL OFL (`Archivo-LICENSE.txt`)
- JetBrains Mono 500 Latin: @fontsource/jetbrains-mono v5.2.5, SIL OFL (`JetBrains-Mono-LICENSE.txt`)

서체 파일은 jsDelivr의 원본 릴리스 경로에서 TLS 검증을 유지해 내려받았습니다. 로고 워드마크는 CI 가이드의 SVG 원본을 사용합니다.

기존 `archivo-black.woff`와 `black-han-sans-korean.woff`는 이전 버전의 자산이며 새 홈페이지에서 참조하지 않습니다.
