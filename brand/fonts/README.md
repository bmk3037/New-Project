# 브랜드 글꼴

| 글꼴 | 용도 | 받는 곳 | 라이선스 |
|---|---|---|---|
| **Archivo** | 영문 디스플레이 · 로고 (굵기 800, 폭 115) | [Google Fonts](https://fonts.google.com/specimen/Archivo) | SIL OFL 1.1 |
| **Pretendard** | 국문 헤드라인 · 본문 (400 / 700 / 900) | [GitHub Releases](https://github.com/orioncactus/pretendard/releases) | SIL OFL 1.1 |
| **JetBrains Mono** | 라벨 · 숫자 · 코드 (500 / 700) | [Google Fonts](https://fonts.google.com/specimen/JetBrains+Mono) | SIL OFL 1.1 |

- 모두 무료로 상업적으로 사용할 수 있습니다.
- 웹에서는 `index.html`처럼 Google Fonts(Archivo, JetBrains Mono)와 jsDelivr(Pretendard)로 불러옵니다.
- 로고 SVG는 글자를 아웃라인(path)으로 바꿔 두었기 때문에 글꼴이 없어도 똑같이 보입니다.
